# Artify Tools: backlink kit

Why: tools.artifysols.com has about 11 referring domains. Competitors have tens of thousands, so links are the biggest gap. Do a few every week; none of these needs paid tools.

## One-line pitch (copy and paste)
**Short:** Free browser-based PDF, image and document tools. Nothing is uploaded: files stay on your device. English and Arabic.
**Long:** Artify Tools (https://tools.artifysols.com) is a free set of online tools that run in your browser, so documents are never uploaded. It includes PDF tools (merge, split, crop, organize, remove pages, compress, rotate, sign, convert), a bank statement converter with manual table selection, a cheque printer with country, bank and size presets, an English/Arabic amount-in-words tool and a document translator. The whole site is available in Arabic.

**Arabic:** أدوات Artify مجموعة أدوات مجانية تعمل داخل المتصفح دون رفع ملفاتك: أدوات PDF (دمج وتقسيم وقص وحذف صفحات وضغط وتدوير وتوقيع وتحويل)، ومحوّل كشوف الحساب البنكية، وطباعة الشيكات، وتفقيط المبالغ بالعربية والإنجليزية، ومترجم المستندات. الموقع متاح بالعربية بالكامل. https://tools.artifysols.com/ar

## 1. Directories and profiles (about an hour, one time)
Submit the site to each, using the pitch above. Use a consistent name ("Artify Tools"), the logo from `/public/brand`, and link to the home page.
- Product Hunt (launch day, with a short demo GIF of Crop PDF turning and straightening a page)
- AlternativeTo (list as an alternative to ilovepdf and Smallpdf; tick "privacy" and "runs locally")
- SaaSHub and similar software directories
- Hacker News "Show HN" and Indie Hackers (lead with the privacy angle: nothing is uploaded)
- Reddit: r/InternetIsBeautiful, r/SideProject, r/pdf (read each subreddit's rules first and don't spam)
- GitHub: add the site URL and a short description to the repository, and to "awesome" lists for browser-based or privacy-friendly tools
- Social profiles with the site link: LinkedIn page, X, Facebook page, YouTube channel

## 2. Arabic-language sources (your best advantage)
- Hsoub I/O (io.hsoub.com): post as a project with the Arabic pitch
- Arabic tech and freelancing communities and Telegram/Facebook groups for accountants and cheque users in the Gulf
- Short Arabic guides (see section 4) shared there

## 3. Content that earns links
Write these as pages or articles on the site, then share them:
1. "How to remove pages from a PDF without uploading it" (links to Remove Pages from PDF)
2. "How to crop shipping labels in a PDF for marketplace sellers" (links to Crop PDF)
3. "How to write amounts in words on a cheque in English and Arabic" (links to Amount in Words and Cheque Printer)
4. "How to print a cheque on any size: measure it from an A4 scan" (links to Cheque Printer)
5. "Convert a bank statement PDF to Excel and check the balance" (links to Bank Statement Converter)

## 4. Outreach template (for bloggers and resource pages)
Subject: Free private PDF tools for your [list / guide name]

Hi [name], I saw your page "[page title]". I run Artify Tools, a free set of PDF and document tools that work in the browser without uploading files (so they suit sensitive documents), with an Arabic version too. The [specific tool] might be a useful addition to your list: [tool URL]. Happy to answer any questions. Thanks, [your name]

Send 5 a week, only to pages where the tool genuinely fits. Track replies in a sheet (page, URL, date, result).

## 5. Quick wins already in the site
- Every tool page has FAQ, how-to and structured data, and an Arabic version with hreflang
- A sidebar of related tools on every tool page links the tools together
- IndexNow key is in place; new pages can be pushed to Bing, Yandex and Naver
